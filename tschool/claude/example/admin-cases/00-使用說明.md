# 行政文件案例庫（虛構）

這一包是王老師過去發過的 6 份行政文件，學校、人名、日期、費用全部是虛構的，只用來練習。

| 檔案 | 類型 | 對象 |
| --- | --- | --- |
| 01-校外教學行前通知 | 活動通知（校外、要收費、要同意書） | 五年級家長 |
| 02-親子共讀夜活動通知 | 活動通知（校內、免費、要報名） | 五年三班家長 |
| 03-班親會邀請通知 | 會議邀請 | 五年三班家長 |
| 04-校慶運動會家長通知 | 全校活動通知 | 全校家長 |
| 05-流感防疫提醒通知 | 健康與防疫提醒 | 五年三班家長 |
| 06-家長志工招募公告 | 招募公告 | 全校家長 |
| 07-本學期活動一覽.csv | 這學期的活動安排（會變動） | 放 Google Drive 用連結參考 |

每份文件分成三段：

- 開頭的表格：類型、對象、發出日期、承辦
- 通知全文：當時發出去的版本
- 發出後的紀錄：家長問最多的問題、下次要改的地方

## 怎麼用

1. 在 Claude 建立一個 Project，名稱填「行政文件案例庫」
2. 把 01～06 六個檔案拖進專案的 Files；07 放到 Google Drive，用連結加入
3. 在這個專案裡開新對話，用 Skill 請 AI 找出最接近的案例來改寫

## 提醒

- 案例裡的日期、時間、地點、費用都是過去的，寫新通知時不能沿用
- 之後發完新的通知，可以把那一份和家長問到的問題存回案例庫
