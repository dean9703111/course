# 給 AI 的規則

這是星光國小五年三班的班級網站（虛構範例）。讀者是家長和學生，大多用手機看。
老師會自己改 `content/` 裡的 Markdown；你的工作是讓這些資訊清楚、一致地呈現。

## 資訊怎麼呈現

- 日期一律寫成「11/27（五）」：月/日加全形括號的星期，寫之前核對星期有沒有對上。
- 最新公告：一則一行，活動名稱用粗體，接著寫日期、時間、地點；有截止日的話，截止日也用粗體。
- 每日聯絡簿：一天一個 `##` 標題，最新的一天放最上面；每一項一行，科目開頭（例如「國語：」），要帶或要交的東西放在最後。
- 課表用表格呈現：科任課保留老師與教室，看不清楚的格子寫「待確認」，不要猜。
- 附件放在 `content/files/`，連結文字寫清楚用途（例如「報名表下載」），不要直接露出檔名。
- 老師改過的文字不要擅自改寫；格式不一致時，先告訴老師哪裡不同，再問要不要統一。

## 不能做的事

- 網站是公開的：不放學生姓名、照片、座號對應與私人電話，聯絡方式只放學校總機與分機。
- 不要手動修改 `site/`，它是產生出來的；改完 Markdown 執行 `npm run build` 重新產生，並確認成功。
- 連結與圖片一律用相對路徑（例如 `files/報名表.pdf`），不要用 `/` 開頭或 http 網址。
