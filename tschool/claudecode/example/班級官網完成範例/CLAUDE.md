# 五年三班 班級網站：給 AI 的規則

星光國小五年三班的公開班級網站，讀者是家長和學生，主要用手機看。

## 檔案結構

- `content/`：網站內容，**只改這裡**
  - `index.md`：首頁（班級資料、班呼、最新公告、導師的話、班級公約、聯絡老師）
  - `timetable.md`：課表
  - `contact-book.md`：每日聯絡簿
- `build.js`：把 Markdown 轉成網頁，只用 Node.js，不需安裝套件
- `package.json`：常用指令（沒有任何套件，不用 `npm install`）
  - `npm run build`：產生網頁一次
  - `npm run dev`：即時預覽，開在 http://localhost:3000（被占用會自動改 3001、3002…），存檔後瀏覽器自動重新整理。自動重新整理的程式碼只在預覽時插入，不會寫進 `site/` 的檔案
- `site/`：產生出來的網站，可直接用瀏覽器打開 `site/index.html`
  - `index.html`、`schedule.html`、`homework.html` 是產生的，**不要手改**，改了下次產生會被蓋掉
  - `style.css` 是手寫的版面，老師已確認滿意，沒被要求就不要動
- `website-materials/`：老師提供的原始素材，只讀不改

改完內容一定要跑 `npm run build`，並看輸出有沒有「請檢查」警告。警告不會讓網頁產生失敗，但每一條都要處理或回報給老師。

## 不能放上網站的內容（公開網站）

- 學生姓名（包括只寫名字、綽號、座號加姓名）
- 學生照片或任何圖片
- 私人電話（家長、老師的手機）。唯一可以放的是學校總機 `(02) 2999-0000 轉 21`
- 老師一律寫「王老師」「林老師」這種姓氏稱呼，不寫全名

素材裡出現上述資料時直接略過，並告訴老師略過了什麼。

## 日期與時間怎麼寫

- 日期：`月/日（星期）`，括號用**全形**，星期只寫一個字。例：`12/4（五）`、`11/25（三）`
  - 不寫年份；不寫「星期五」「週五」在括號內；不用半形 `(五)`
  - build.js 會依 `學期` 推算年份並檢查星期對不對（115 學年度 = 2026/8～2027/7）
- 時間：24 小時制、兩位數，例：`07:40`、`18:30`
- 時間範圍用全形波浪號：`18:30～20:00`；課表節次時間用 en dash：`08:40–09:20`
- 頁碼：`p.40`、範圍 `p.66～67`

## 首頁 `index.md`

最上面 `---` 之間是班級資料（`學校`、`班級`、`學期`、`導師`、`教室`），全站共用。

接著依序用 `# ` 分段，標題文字要完全一樣：`# 班呼`、`# 最新公告`、`# 導師的話`、`# 班級公約`、`# 聯絡老師`。

- **班呼**：一行就是黑板上的一行，最多兩行比較好看。
- **導師的話**：一般段落與 `1.` 清單；最後一行 `署名: 王老師` 會靠右顯示。
- **班級公約**：`1.` 編號清單。
- **聯絡老師**：一般段落；`電話: (02) 2999-0000 轉 21` 會變成可以直接撥打的按鈕。

### 公告格式

每則公告一個 `## 標題`，**最新、最重要的放最上面**。內容依序：

```markdown
## 親子共讀夜

印章: 報名中

一兩句說明活動是什麼、為什麼辦。

- 時間: 12/11（五）18:30～20:00
- 地點: 星光國小圖書室
- 費用: 免費

### 截止日

- 12/4（五）: 報名表交給導師

### 活動流程與注意事項

- 細節一條一行
```

- `印章:` 可省略；是右上角的紅色章，2～3 個字，例如「報名中」「重要」「已結束」。
- `- 項目: 內容` 清單是重點資訊，項目名稱 2 個字（時間、地點、對象、費用、攜帶、日期、集合、回校）。
- `### 截止日`：每行 `- 日期: 要家長做的事`，依日期由早到晚排，會用紅筆波浪線標出。沒有期限就整段省略。
- 其他 `### 標題` 會變成可展開的區塊，按鈕文字是「看＋標題」，所以標題不要再加「看」。
- 活動結束的公告直接刪掉，不要堆著。

## 課表 `timetable.md`

- `# 功課表` 下面的段落是黑板上的副標題，每行一行。
- `## 課表` 是 Markdown 表格，欄位固定：`節次 | 時間 | 週一 … 週五`。
  - 格子寫法：`科目` 或 `科目（老師・教室）`，括號裡的字會變成小字備註。
  - 下課、午休那列：週一到週五的格子全部留空，就會變成休息列。
  - 沒課提早放學：寫 `放學 12:40`，連續幾節都這樣寫會自動合併；第一格可加說明 `放學 12:40（吃完午餐後整隊放學）`。
- `## 科目顏色`：左欄只能用這 10 種顏色：國語、數學、英語、自然、社會、健體、藝術、綜合、本土語、彈性。右欄列出用這個顏色的科目，用「、」分隔。沒列到的科目（如升旗典禮）不上色。
- `## 小提醒`：`- ` 清單。
- 「今天」是瀏覽器依當天日期自動標示，不用改。

## 聯絡簿 `contact-book.md`

```markdown
## 11/26（四）

1. 國習 12
2. 數習 p.41
3. 明天帶水彩用具
```

- 每天一個 `## 日期`，**新的一天加在最上面**；最上面那天會自動蓋「最新」章，不用手動標。
- 每項用 `1.` 編號，一項一件事，照聯絡簿原本的縮寫抄（國習、數課、數習…），不要改寫成長句。
- 要帶的東西寫成 `剪刀、膠水（自然課）`：物品在前、用途放全形括號。
- 只保留最近一兩週，太舊的刪掉。
- `# 給家長` 是頁面最下方固定的提醒，可用 `**粗體**` 強調。

## 通用 Markdown 規則

- 段落內換行會照樣換行（中文不會自動接起來）。
- 支援 `**粗體**` 和 `[文字](網址)`；不要用圖片、HTML 標籤。
- `<!-- 註解 -->` 不會出現在網頁上。
- 冒號 `:` 或 `：` 都可以。
