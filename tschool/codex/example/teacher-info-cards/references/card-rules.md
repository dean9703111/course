# 資訊卡寫作規則

## 封面主標：先講對方的處境

| 寫法 | 例子 |
|---|---|
| 對方會說出口的疑問 | 「親子共讀夜要帶什麼？」 |
| 一個關鍵行動＋期限 | 「12/4 前交回報名表」 |
| 一個數字＋承諾（數字要出自素材） | 「3 個訣竅，分辨事實與意見」 |
| 對比 | 「不是有數字就叫事實」 |

- 主標 8～18 字，用 `<mark>` 標 1 個關鍵詞
- 不要用「○○活動通知」「第三單元重點」這種文件標題當主標

## 排卡結構（4～7 張）

| 素材類型 | 建議排法 |
|---|---|
| 家長通知／活動公告 | 封面 → 活動資訊（facts）→ 流程（flow）→ 要帶什麼／怎麼報名（list）→ 注意事項（yes／nope 或 warn）→ 重點回顧 |
| 教材重點 | 封面 → 概念一 → 概念二 → 常見錯誤（yes／nope）→ 判斷步驟（flow 或 ol.list）→ 重點回顧 |
| 班級規範／SOP | 封面 → 為什麼 → 步驟（ol.list）→ 例外與提醒（warn）→ 重點回顧 |

## 可用元件（只用這些）

| 元件 | 寫法 | 用途 |
|---|---|---|
| 膠囊標籤 | `<span class="badge">…</span>` | 封面上方的分類 |
| 卡片小標 | `<span class="no">…</span>` | 內容卡最上方，例如「活動資訊」 |
| 大標 | `<h1>`（封面）／`<h2>`（內容卡，一卡一個） | 標題 |
| 螢光標記 | `<mark>…</mark>` | 封面關鍵詞，一卡最多 1 個 |
| 副標、段落 | `<p class="sub">`／`<p>` | 一兩句說明 |
| 一句話重點 | `<p class="big">…</p>` | 整張卡的主角句 |
| 強調字 | `<span class="hot">…</span>` | 截止日、不能錯的數字 |
| 資訊列 | `<div class="facts"><div><b>日期</b><span>…</span></div></div>` | 日期、時間、地點、對象、費用 |
| 條列 | `<ul class="list"><li><b>重點</b>：說明</li></ul>`；有順序用 `<ol class="list">` | 2～4 項 |
| 流程 | `<div class="flow"><div><span>18:30</span>步驟</div></div>`；最重要的一步加 `class="key"` | 時間表、操作步驟 |
| 對照 | `<p class="yes">…</p>`／`<p class="nope">…</p>` | 要這樣做 vs 不要這樣做 |
| 提醒 | `<p class="tip">…</p>`／`<p class="warn">…</p>` | 每卡的記憶點／例外與警告 |
| 來源 | `<p class="source">資料來源：…</p>` | 最後一張卡 |

## 字數上限（超過就拆卡或精簡）

- 封面主標 ≤ 18 字；副標 ≤ 30 字
- 內容卡 `h2` ≤ 14 字
- 條列每項 ≤ 28 字，一卡最多 4 項
- 資訊列一卡最多 5 列；流程一卡最多 6 步
- 一張卡只放 1 個主要元件＋1 個提醒

## 交付前檢查清單

- [ ] 第一張是 `cover`、最後一張是 `summary`，總數 4～7 張
- [ ] 日期、星期、時間、地點、人數、金額與素材逐字相同
- [ ] 沒有素材以外的資訊；缺漏寫在最後一張「待老師補充」
- [ ] 沒有學生全名、照片、電話等個資
- [ ] 每張卡只講一件事，沒有超過字數上限
- [ ] 最後一張有「資料來源：檔名」
- [ ] 沒有改動樣式區、程式區，也沒有外部網址
