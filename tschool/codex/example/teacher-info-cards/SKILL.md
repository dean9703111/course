# 老師版資訊卡（teacher-info-cards）

素材 → 提煉摘要（先給老師確認）→ 複製 HTML 模板、只改內容區 → 自我檢查 → 交付一個 `.html` 檔

## 資源

| 檔案 | 用途 |
|---|---|
| `assets/cards-template.html` | 資訊卡模板：樣式、下載 PNG、列印都已內建，只需要改「內容區」 |
| `references/card-rules.md` | 封面寫法、排卡結構、可用元件、字數上限、檢查清單；開始前先讀 |

## 流程

### STEP 1：讀素材，先給提煉摘要

讀完使用者指定的檔案（或貼上的文字），先回覆以下 5 點，等老師說「OK」再做卡片；老師說「直接做」就略過等待，但摘要仍要列出：

1. **核心一句話**：這組卡只為這句話服務
2. **給誰看**：家長、學生或同事；他們最在意什麼
3. **封面主標**：寫成對方會說出口的話，不要直接用文件標題
4. **排卡大綱**：4～7 張，每張一行（封面、內容卡、重點回顧）
5. **素材缺什麼**：日期、地點、聯絡方式等缺漏，寫成「待老師補充」，不要自己補

### STEP 2：複製模板，只改內容區

1. 把 `assets/cards-template.html` 複製到使用者指定的輸出資料夾（沒指定就放 `output/`），檔名 `<主題>_資訊卡.html`；不要修改 Skill 資料夾裡的模板本身
2. 只改這三處：
   - `<title>` 與工具列的 `<strong>`：換成主題
   - `<body>` 的 `data-label`（每張卡底部的標籤，例如「五年三班｜親子共讀夜」）與 `data-theme`（campus 黑板綠／sky 天空藍／warm 暖橘；沒指定用 campus）
   - 「內容區」裡的 `<section class="card …">`：依大綱增刪卡片，用 `references/card-rules.md` 列的元件
3. 不要改樣式區與程式區，不要加外部圖片、字型或其他網址

### STEP 3：自我檢查（交付前必做）

逐項對照 `references/card-rules.md` 的檢查清單，特別是：

- 日期、時間、地點、金額、人數，**逐字對照素材**，一個字都不能改
- 素材沒有的資訊不寫；缺的就在最後一張卡寫「待老師補充：…」
- 每張卡沒有超過字數上限（超過就拆卡或精簡）
- 最後一張卡有「資料來源：檔名」

### STEP 4：交付

回覆老師：

- 檔案位置，以及「用 Chrome／Edge／Safari 打開這個 HTML 檔」
- 要圖片：按「下載全部 PNG」（需要網路），或「列印／存成 PDF」
- 需要老師確認的地方（缺漏、你不確定的措辭）
- 想修改就直接說「第 3 張改成…」，你會改 HTML 後請老師重新整理頁面

## 禁止事項

- 不編造日期、地點、人數、金額、聯絡方式或任何素材沒有的承諾
- 不放學生全名、照片、聯絡電話等個資；素材裡有就提醒老師移除
- 不使用外部圖片或網路字型；不修改模板的樣式與程式
