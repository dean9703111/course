# 圖片 Prompt 模板

把 `[ ]` 內的變數換掉即可；沒特別指定就用預設值。「固定風格」段落四種圖共用。

## 固定風格（每個模板最後都要加）

```
風格：溫暖手繪插畫，線條簡單；配色以黑板綠、向日葵黃、紙張米白為主，搭配一個強調色。
背景：乾淨的淺色背景，不要複雜底圖。
文字：繁體中文，清晰的無襯線字體，標題大、內文精簡，文字不要壓在圖案上。
限制：不要出現真實人物臉孔、知名動漫角色、品牌 Logo；圖上的日期、時間、地點請與提供的資料完全一致。
```

## A. 懶人包

```
請生成一張給[家長]看的懶人包圖片，比例[4:5 直式]。

主題：[親子共讀夜]
重點 1：[12/11（五）18:30～20:00，圖書室]
重點 2：[每位學生最多 2 位家長陪同，免費參加]
重點 3：[12/4（五）前把報名表交給導師]
一句話總結：[帶一本喜歡的書，全家一起來共讀]

版面：上方是主題，中間三個重點各搭配一個小圖案，下方是一句話總結。
[固定風格]
```

## B. 行程表

```
請生成一張[活動名稱]的行程表圖片，比例[1:1]。

行程（由上到下排列，每一列左邊是時間、右邊是事項，旁邊加一個對應的小圖案）：
[18:30 開場與暖身遊戲]
[18:45 親子共讀]
[19:20 「事實還是意見？」親子挑戰]
[19:45 分享與合照]
[20:00 賦歸]

[固定風格]
```

## C. 流程圖

```
請把下面的步驟設計成流程圖，讓[國小高年級學生]可以快速掌握，比例[16:9]。

主題：[用紫色高麗菜汁檢驗酸鹼]
步驟（依序編號，用箭頭連接，每一步搭配簡單圖示，文字不超過 12 個字）：
1. [切碎高麗菜，泡熱水 10 分鐘]
2. [把菜汁倒進 4 個杯子]
3. [分別加入白醋、檸檬汁、小蘇打水、肥皂水]
4. [觀察顏色變化並記錄]
5. [變紅是酸性，變藍綠是鹼性]

[固定風格]
```

## D. 活動海報

```
請設計一張[活動名稱]的海報，比例[3:4 直式]。

主題：[115 學年度校慶運動會]
標語：[活力全開，為班級而跑]
時間：[12/5（六）08:30～12:00]
地點：[學校操場（雨天改到活動中心）]
活動亮點：[大隊接力、趣味競賽、親子拔河、社團表演]
參加對象：[全校師生，歡迎家長一起參加]

版面：主題最大，標語次之；時間與地點放在下方的資訊區，用網格對齊；適當留白。
[固定風格]
```

## 比例對照

- 4:5 直式：LINE 班群、聯絡簿貼圖（懶人包預設）
- 1:1：班群、簡報內頁（行程表預設）
- 16:9：簡報、學習單橫式（流程圖預設）
- 3:4 直式：列印張貼（海報預設）

## 換風格時的說法

- 可愛日系插畫：圓潤線條、粉彩配色
- 向量扁平化：幾何圖形、純色塊，適合流程圖
- 黑板粉筆風：深綠背景、白色與黃色粉筆線條
