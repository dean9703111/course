# 信件範例（虛構）

學校、老師、家長與活動都是虛構的教學素材。只學結構與長度，不要照抄句子。

## 範例 1：回覆家長詢問（Email）

家長來訊：「老師好，親子共讀夜可以帶弟弟一起去嗎？」

```
家長您好：

謝謝您的來訊，也很開心您願意全家一起參加。

因為圖書室的座位有限，這次每位學生最多 2 位家長陪同，弟弟妹妹暫時沒辦法一起入場，還請見諒。

如果當天需要有人協助照顧弟弟，可以這樣安排：
- 由一位家長陪同孩子參加
- 活動 20:00 結束，可以在校門口會合

報名表請在 12/4（五）前交給我。有任何問題，歡迎在聯絡簿留言。

導師 王老師 敬上
```

## 範例 2：全班提醒（LINE 班群公告）

```
各位家長您好：
提醒您，親子共讀夜的報名表請在 12/4（五）前交回。
📅 12/11（五）18:30～20:00
📍 圖書室
請記得帶一本家裡喜歡的書和水壺。
謝謝您的配合。
五年三班導師 王老師
```

## 範例 3：給主任的信（Email）

```
陳主任您好：

五年三班預計在 12/11（五）18:30～20:00 借用圖書室舉辦親子共讀夜，想請您協助確認兩件事：

1. 當晚圖書室是否可以借用到 20:30（含場地復原）
2. 是否需要另外填寫場地借用單

再請您指示，謝謝。

五年三班導師 王小美 敬上
```

## 範例 4：回覆聯絡簿留言

```
謝謝您的提醒，孩子今天已經把學習單補交了。之後我會在聯絡簿上多寫一行繳交日期，方便您在家確認。王老師
```
