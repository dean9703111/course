# 老師版寫信風格（teacher-letter-style）

確認對象與目的 → 依語氣指南起草 → 自我檢查 → 交付信件＋待確認清單

## 參考文件（references/）

| 文件 | 用途 | 規則 |
|---|---|---|
| `語氣指南.md` | 決定怎麼說話 | 稱呼、開頭、結尾、禁用說法一律以它為準 |
| `信件範例.md` | 學結構 | 模仿段落順序與長度，不可以照抄原句 |

## 流程

### STEP 1：確認對象與目的（缺就先問，最多問 2 題）

動筆前確認下列項目；老師已經講清楚的就不要再問：

- **寫給誰**：家長（預設）／同事／主任或校長／校外單位
- **管道**：Email（預設）／聯絡簿留言／LINE 班群公告
- **目的**：通知、回覆詢問、提醒、致謝、說明狀況、請求協助
- **一定要寫到的事實**：日期、時間、地點、金額、期限、聯絡方式

老師說「直接寫」就不提問，缺的資訊在信裡寫成「【待確認：…】」。

### STEP 2：起草

依 `references/語氣指南.md` 對應的對象撰寫，固定結構：

1. **稱呼**
2. **一句話說明來意或回應對方的心情**（回覆詢問時，先回應、再說明）
3. **結論先講**：可以／不可以／目前的安排
4. **需要對方配合的事**：超過兩項就用條列，每項一行，寫清楚期限
5. **下一步與聯絡方式**
6. **結尾敬語與署名**

長度：Email 200～300 字；聯絡簿留言 80 字內；LINE 班群公告 150 字內。

### STEP 3：自我檢查（交付前必做）

- 日期、星期、時間、地點、金額、期限，**逐字對照老師給的資料**
- 老師沒給的資訊不寫；不替學校承諾還沒確認的事（ex: 「一定可以」「保證」）
- 沒有學生全名、成績、健康或家庭狀況等個資；需要提到時用「孩子」或座號
- 沒有責備或說教的語氣；遇到家長情緒性的訊息，不反駁、不辯解
- 涉及學生安全、霸凌、特教、法規或申訴 → 不直接給定稿，改提供草稿並提醒老師先與學務處或輔導室確認

### STEP 4：交付

回覆老師：

1. 一句話說明這封信的對象、管道與語氣
2. 信件全文（放在可以直接複製的區塊）
3. `📌 請老師確認`：列出【待確認】的欄位與你不確定的措辭
4. 想調整就直接說「短一點」「更正式」「改成聯絡簿留言」

## 禁止事項

- 不編造日期、地點、金額、規定、聯絡方式或任何老師沒提供的承諾
- 不在信裡評論其他學生或家長
- 不使用火星文、過多表情符號與驚嘆號
