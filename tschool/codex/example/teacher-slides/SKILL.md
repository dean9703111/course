# 模板簡報設計師（teacher-slides）

簡報的目的是**讓聽眾聽完知道重點、知道要做什麼**，不是把資料全部搬上去。每一頁只說一件事，標題就是結論。

## 資源

| 檔案 | 用途 |
|---|---|
| `assets/School_Slides_Template.pptx` | 校園風格模板（16:9）：第 1 頁封面、第 2 頁使用說明、第 3～15 頁為版型 02～14 |
| `references/layouts.md` | 14 種版型的用途、可填欄位、內容上限、各場合的建議頁序、簡報計畫 JSON 範例；選版型前先讀 |
| `scripts/extract_docx.py` | 把 Word（.docx）拆成「內容.md＋圖片」；只用 Python 3 內建功能 |
| `scripts/build_deck.py` | 依簡報計畫套用模板產出 .pptx，圖片自動放進照片框；只用 Python 3 內建功能，不需要安裝套件 |

視覺已內建在模板，不要另創配色：紙張米白、黑板綠、向日葵黃、珊瑚橘（只用在提醒與截止日）、天空藍；字體微軟正黑體。

## 流程（每一步先給使用者確認，再往下）

### STEP 1：讀素材、釐清需求

**素材是 Word（.docx）時，先拆出文字與圖片**（不要只憑檔名猜內容）：

```
python3 <本 Skill 資料夾>/scripts/extract_docx.py <教材.docx>
```

- 產出 `output/<檔名>_素材/內容.md` 與 `圖片/圖NN.*`；腳本會列出每張圖的位置、尺寸、所在段落與圖說
- 一次可以給多份 .docx；舊版 `.doc` 請使用者先在 Word 另存成 `.docx`
- 化學式的上下標會保留成 H₂SO₄、OH⁻；產出後抽幾個對照原文件

缺的一次問完，不要一題一題問：

- **場合與聽眾**：上課（學生）、班親會（家長）、教學觀摩或研習分享（同事）、活動說明（學生或家長）
- **一句話結論**：聽完要記得什麼、要做什麼
- **時間或頁數**：沒說就預設 10 頁內
- **素材範圍**：只用使用者提供的檔案與文字；缺的資訊標「[待補：…]」，不要自己編日期、數字、人名

### STEP 2：生成大綱（不寫內文）

用表格輸出，等使用者確認：

| 頁碼 | 標題（結論句，≤ 16 字） | 這頁的任務 | 版型 | 用到的圖 |
|---|---|---|---|---|

- 開頭先講聽眾在意的事；結尾要有明確的「下一步」「請您配合」或課堂練習
- 一頁只解一個任務；同類內容合併，不湊頁數；教材的內容不必每一段都上簡報
- 版型從 `references/layouts.md` 挑，同一個版型連續不超過 2 頁
- **圖片**：素材有圖時，在「用到的圖」寫圖號（例如 3-2 講義的圖 1）；只有版型 01、06、14 有照片框，一頁放一張；沒用到的圖在大綱下方列出來，讓使用者決定要不要加頁
- 教師版教材裡的紅字答案、座號姓名欄不要放進給學生看的簡報；要不要放答案先問

### STEP 3：逐頁預覽（文字描述）

每頁列出：版型編號、觀眾第一眼看到什麼、各欄位的文字草稿、用哪張圖。使用者說 OK 才產出；有調整就改預覽，不要直接重做整份。

### STEP 4：產出 PPTX

1. 依預覽寫一份簡報計畫 `output/<主題>_簡報計畫.json`（格式見 `references/layouts.md`；要看每個版型的欄位名稱，可執行 `python3 scripts/build_deck.py --list`）；有圖的頁加上 `"image": "output/<檔名>_素材/圖片/圖NN.jpg"`
2. 執行：`python3 <本 Skill 資料夾>/scripts/build_deck.py output/<主題>_簡報計畫.json`（Windows 若沒有 `python3`，改用 `python` 或 `py`）
3. 看腳本最後的「需要確認的地方」：字數超過就精簡或拆頁；還有範本文字就補上或刪掉；圖片沒放進去就照訊息處理；修改計畫後重跑
4. 腳本無法執行（找不到 Python、執行失敗）時：
   - 不要自行安裝軟體，也不要假裝已經產出
   - 如果目前環境有內建的簡報功能，可以改用它，並以這份模板為參考
   - 都不行時，改輸出 `output/<主題>_逐頁稿.md`：每頁寫版型編號、各欄位文字與要放的圖，告訴使用者可以複製模板頁手動貼上，或把這個技能包上傳到 ChatGPT 的「技能」在雲端產出

### STEP 5：交付

回覆使用者：

- 檔案位置；請用 PowerPoint、Keynote 或 Google 簡報打開檢查（字型會依電腦替換，請看有沒有跑版）
- 頁數與版型對照表；每張圖放在第幾頁、哪幾張圖沒有用到
- 待補清單：還空著的照片框、[待補] 的數字與日期、聯絡方式
- 內容是從哪一份素材整理的；素材沒寫、需要使用者確認的地方
- 學生照片要先確認家長是否同意入鏡

## 禁止事項

- 不編造日期、數字、人名、成績或活動成果；沒有來源的數字不放進「數字亮點」
- 不改寫素材裡的定義、公式、化學式與實驗步驟；要精簡就縮短句子，不改變意思
- 不放學生全名、聯絡電話、成績等個資
- 不改模板配色與字體，不用高飽和色
- 不塞滿：超過版型容量就拆頁或換版型
- 不跳過確認直接產出整份簡報（使用者明確說「直接做」時，大綱仍要列在回覆裡）
