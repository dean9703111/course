# 校園簡報設計師（teacher-slides）

簡報的目的是**讓聽眾聽完知道要做什麼**，不是把資料全部搬上去。每一頁只說一件事，標題就是結論。

## 資源

| 檔案 | 用途 |
|---|---|
| `assets/School_Slides_Template.pptx` | 校園風格模板（16:9）：第 1 頁封面、第 2 頁使用說明、第 3～15 頁為版型 02～14 |
| `references/layouts.md` | 14 種版型的用途、可填欄位、內容上限、三種場合的建議頁序、簡報計畫 JSON 範例；選版型前先讀 |
| `scripts/build_deck.py` | 依簡報計畫套用模板產出 .pptx；只用 Python 3 內建功能，不需要安裝套件 |

視覺已內建在模板，不要另創配色：紙張米白、黑板綠、向日葵黃、珊瑚橘（只用在提醒與截止日）、天空藍；字體微軟正黑體。

## 流程（每一步先給老師確認，再往下）

### STEP 1：釐清需求

缺的一次問完，不要一題一題問：

- **場合與聽眾**：班親會（家長）、教學觀摩或研習分享（同事）、學生活動說明（學生或家長）
- **一句話結論**：聽完要記得什麼、要做什麼
- **時間或頁數**：沒說就預設 10 頁內
- **素材**：只用老師提供的檔案與文字；缺的資訊標「[待補：…]」，不要自己編日期、數字、人名

### STEP 2：生成大綱（不寫內文）

用表格輸出，等老師確認：

| 頁碼 | 標題（結論句，≤ 16 字） | 這頁的任務 | 版型 |
|---|---|---|---|

- 開頭先講聽眾在意的事，結尾要有明確的「請您配合」「下一步」或聯絡方式
- 一頁只解一個任務；同類內容合併，不湊頁數
- 版型從 `references/layouts.md` 挑，同一個版型連續不超過 2 頁

### STEP 3：逐頁預覽（文字描述）

每頁列出：版型編號、觀眾第一眼看到什麼、各欄位的文字草稿。老師說 OK 才產出；有調整就改預覽，不要直接重做整份。

### STEP 4：產出 PPTX

1. 依預覽寫一份簡報計畫 `output/<主題>_簡報計畫.json`（格式見 `references/layouts.md`；要看每個版型的欄位名稱，可執行 `python3 scripts/build_deck.py --list`）
2. 執行：`python3 <本 Skill 資料夾>/scripts/build_deck.py output/<主題>_簡報計畫.json`（Windows 若沒有 `python3`，改用 `python` 或 `py`）
3. 看腳本最後的「需要確認的地方」：字數超過就精簡或拆頁；還有範本文字就補上或刪掉；修改計畫後重跑
4. 腳本無法執行（找不到 Python、執行失敗）時：
   - 不要自行安裝軟體，也不要假裝已經產出
   - 如果目前環境有內建的簡報功能，可以改用它，並以這份模板為參考
   - 都不行時，改輸出 `output/<主題>_逐頁稿.md`：每頁寫版型編號與各欄位文字，告訴老師可以複製模板頁手動貼上，或把這個技能包上傳到 ChatGPT 網頁版的「技能」在雲端產出

### STEP 5：交付

回覆老師：

- 檔案位置；請用 PowerPoint、Keynote 或 Google 簡報打開檢查（字型會依電腦替換，請看有沒有跑版）
- 頁數與版型對照表
- 待補清單：照片（照片框要自己放或刪）、[待補] 的數字與日期、聯絡方式
- 學生照片要先確認家長是否同意入鏡

## 禁止事項

- 不編造日期、數字、人名、成績或活動成果；沒有來源的數字不放進「數字亮點」
- 不放學生全名、聯絡電話、成績等個資
- 不改模板配色與字體，不用高飽和色
- 不塞滿：超過版型容量就拆頁或換版型
- 不跳過確認直接產出整份簡報
