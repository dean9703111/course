# 老師版線上課堂講義（teacher-class-handout）

教案／筆記 → 講義大綱（先給老師確認）→ 複製 HTML 模板、只改內容區 → 自我檢查 → 交付一個 `.html` 檔

## 資源

| 檔案 | 用途 |
|---|---|
| `assets/handout-template.html` | 講義模板：目錄、字級 A－／A＋、深色、列印都已內建，只需要改「內容區」 |
| `references/components.md` | 可用元件的寫法、段落安排與檢查清單；開始前先讀 |

## 流程

### STEP 1：讀素材，先給講義大綱

讀完使用者指定的檔案，先回覆以下內容，等老師說「OK」再製作；老師說「直接做」就略過等待，但大綱仍要列出：

1. **讀者**：學生（課前預習／課後複習）還是老師自己（上課用）；沒說就問一次
2. **一句話目標**：學完能做到什麼
3. **段落大綱**：3～6 段，每段一行，標出要用的元件（重點卡、比較、步驟、活動、想一想、回家任務）
4. **素材缺什麼**：頁碼、時間、答案不明確的地方，寫成「待老師確認」

### STEP 2：複製模板，只改內容區

1. 把 `assets/handout-template.html` 複製到使用者指定的輸出資料夾（沒指定就放 `output/`），檔名 `<主題>_線上講義.html`；不要修改 Skill 資料夾裡的模板本身
2. 改 `<title>`，以及「內容區開始」到「內容區結束」之間的 `header.hero`、`main.wrap`、`footer`
3. 目錄由程式自動產生：每段用 `<section><h2>…</h2>…</section>`，不用手寫目錄項目
4. 只用 `references/components.md` 列出的元件；不要改樣式區與程式區，不要加外部圖片、字型或網址（素材裡本來就有的參考連結可以保留）

### STEP 3：自我檢查（交付前必做）

- 定義、例句、頁碼、時間與素材一致；素材沒有的答案不要自己編，寫「待老師確認」
- 給學生看的版本：句子短、一段一個重點、名詞第一次出現就解釋
- 「想一想」的參考答案要寫判斷理由，不只寫結論
- `footer` 寫上資料來源檔名

### STEP 4：交付

回覆老師：

- 檔案位置，以及「用 Chrome／Edge／Safari 打開」；要分享給學生可以傳檔案，或放到學校的雲端硬碟
- 列印時「想一想」會自動展開答案；不想印出答案就先刪掉該段
- 需要老師確認的地方
- 想修改就直接說「第 2 段改成…」，你會改 HTML 後請老師重新整理頁面

## 禁止事項

- 不編造課本內容、頁碼、答案或評分標準
- 不放學生姓名、照片等個資
- 不修改模板的樣式與程式，不引入外部資源
