# 講義元件與寫作規則

## 段落安排（3～6 段）

| 講義類型 | 建議段落 |
|---|---|
| 學生預習／複習 | 今天要學什麼 → 重要名詞 → 怎麼判斷（步驟）→ 例題與想一想 → 回家任務 |
| 老師上課用 | 本節目標 → 流程與時間 → 活動說明 → 提問與參考答案 → 課後反思 |
| 活動或校外教學說明 | 活動目的 → 流程時間表 → 分組與注意事項 → 想一想 → 回來後的任務 |

## 可用元件（只用這些）

| 元件 | 寫法 | 用途 |
|---|---|---|
| 段落 | `<section><h2>標題</h2>…</section>` | 每段一個 `h2`，目錄自動產生 |
| 導言 | `<p class="lead">…</p>` | 段落開頭一兩句 |
| 卡片 | `<div class="card"><h3>🎯 標題</h3><ul><li>…</li></ul></div>` | 一個主題的重點；`h3` 用一個語意 emoji 開頭 |
| 卡片並排 | 把多張 `.card` 放進 `<div class="grid">…</div>` | 2～3 個並列重點 |
| 重點句 | `<p class="key">…</p>` | 每段最重要的一句 |
| 警告 | `<div class="warn">…</div>` | 常見錯誤、安全提醒 |
| 名詞解釋 | `<dl class="terms"><dt>名詞</dt><dd>白話解釋</dd></dl>` | 新名詞 |
| 比較 | `<div class="compare"><div><h3>左</h3><ul>…</ul></div><div><h3>右</h3><ul>…</ul></div></div>` | A vs B、對 vs 錯 |
| 步驟 | `<ol class="steps"><li>…</li></ol>` | 有先後順序的做法 |
| 表格 | 一般 `<table><tr><th>…</th></tr><tr><td>…</td></tr></table>` | 時間表、分組表 |
| 活動 | `<div class="activity"><span class="time">10 分鐘</span><h3>活動名稱</h3><ul>…</ul></div>` | 課堂活動 |
| 想一想 | `<details class="quiz"><summary>問題</summary><p class="ans">答案與理由</p></details>` | 點開才看到答案 |
| 回家任務 | `<ul class="todo"><li>…</li></ul>` | 可勾選的任務 |
| 螢光筆 | `<mark>…</mark>` | 句中關鍵詞，一段最多 2 個 |

## 寫作規則

- 一個 `h2` 段落 ≤ 3 個元件；卡片條列每項 ≤ 30 字
- 給學生看的版本用「你」，句子短，避免成語堆疊與術語
- 例句、定義、頁碼照素材；素材之間互相矛盾時，兩種說法都列出並標「待老師確認」
- 不要為了版面好看自己補例子；需要更多例子時，列在回覆中請老師挑選

## 交付前檢查清單

- [ ] `<title>` 與 `h1` 已換成實際主題
- [ ] 每段都是 `<section><h2>`，目錄能正確跳轉
- [ ] 沒有素材以外的事實、頁碼、答案
- [ ] 「想一想」有參考答案與理由
- [ ] `footer` 有資料來源檔名
- [ ] 沒有改動樣式區、程式區，也沒有外部圖片或字型
