# 第 2 堂練習包（生成式 AI 研習）

所有資料都是虛構的教學素材：學校、老師、學生與家長都不是真的，網址也都是示範用的假網址，不可對外使用。

## 資料夾用途

| 資料夾／檔案 | 用途 | 怎麼打開 |
|---|---|---|
| `行動研究` | 第 1 堂「建立專案」用過的 4 份文件；今天不上傳，直接讓 AI 從資料夾讀 | `.md` 是純文字，記事本或文字編輯就能開 |
| `技能包` | 放從講義下載的資訊卡、線上講義、校園簡報技能包（zip 或解壓後的資料夾），再請 Codex 安裝 | — |
| `技能練習` | Skill 練習用的素材：家長通知、上課筆記、班親會資料 | `.md` 是純文字，記事本或文字編輯就能開 |
| `備課資源` | 一個單元的備課資料，格式混在一起（Word、Excel、CSV、文字檔、掃描圖） | Word、Excel、看圖軟體；`.csv` 用 Excel 或 Google 試算表開 |
| `報名表照片` | 放你手寫、拍好的虛構報名表照片 | — |
| `報名表範本.html` | 用瀏覽器打開後列印，一張 A4 有 3 份報名表 | Chrome、Edge、Safari |
| `output` | 課堂上請 AI 產出的成品都放這裡 | — |

## 注意事項

- `行動研究`、`備課資源` 與 `技能練習` 只讀取、不修改；成品一律放 `output`
- `備課資源` 的資料故意有衝突與缺漏，練習時先自己找找看
- 報名表請填虛構資料，只寫班級與座號，不寫真實姓名
- 操作步驟請依課堂講義進行
