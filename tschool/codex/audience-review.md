**審查對象**：`content.md` 2026-11-10 改版（課前回顧、初探 Codex、Skill 起手式、備課資源彙整、報名表照片轉 Excel、課程總結），對照練習包 `codex-practice` 與三個技能包的實際檔案。

## Skill 起手式

### 🟡 隱藏資料夾 `.agents/skills` 對新手太難
- **位置**：「📥 安裝：交給 Codex 搬進個人 Skill 資料夾」。
- **類型**：操作前提缺失。
- **觀眾內心 OS**：「Finder 裡根本找不到 .agents，我要放去哪？」
- **建議**：不要求學員自己找資料夾；下載的 zip 先放進練習資料夾的 `技能包`，用 Prompt 請 Codex 安裝，並提醒核准前看清楚寫入位置。
- **狀態**：已修正；核准提示畫面待補圖（`codex-skill-install.png`）。

### 🟡 `@` 還是 `$`？
- **位置**：「▶️ 呼叫：輸入 @ 選技能」。
- **類型**：術語／介面差異。
- **觀眾內心 OS**：「講義寫 @，旁邊的人打 $ 也跑出來，到底哪個對？」
- **建議**：正文寫「打 `@` 選技能（Codex 也支援 `$`）」，示範 Prompt 一律用 `@`；講師備註標授課前確認現場版本。

### 🟡 40 分鐘塞三個技能，時間容易爆
- **位置**：技能一～三與三個實戰演練。
- **類型**：步驟跳躍／時間壓力。

- **狀態**：已修正（lab-session 的 hint 與任務已寫明）。

## 已確認的優點

- 三個技能包都是「模板寫死樣式、AI 只填內容」，學員之間的成品風格一致，講師好檢查。
- 每個技能都先給摘要／大綱讓老師確認，符合「先確認再產出」的系列習慣，也省額度。
- 備課包與報名表練習都附「對照預期結果」或明確驗收條件，學員能自己判斷 AI 有沒有說得太確定。
- 本審查為講義與素材的書面審查，尚未現場試教；技能包已在講師電腦以模板實測產出，未在學員常見的 Windows 環境實測。
