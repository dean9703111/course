# 閱讀助理練習包

所有角色、活動與資料均為虛構，供第 1 堂練習。這份說明是給人看的，不用上傳到 ChatGPT 專案。

## 裡面有什麼

- `活動條件.md`、`教學目標.md`、`通知格式.md`：閱讀探索日的背景資料與家長通知範本。
- `虛構郵件.txt`：四封籌備討論的往來信。
- `虛構行事曆.txt`：兩筆已經排定的行程。

## 怎麼用

1. 建立專案：把上面五個檔案拖進專案的資料來源，再照講義的問題驗證。
2. 沒有連接 Gmail 或 Google Calendar：打開兩個 `.txt`，把全文貼在講義的 Prompt 下方練習。

這些文字檔本身不是已連接的 Gmail 或 Google Calendar，AI 不會因此讀到你的信箱或行事曆。

第 2 堂會提供同一活動的更多材料。自己的通知與 SOP 請另外保存，不要覆寫此包。
