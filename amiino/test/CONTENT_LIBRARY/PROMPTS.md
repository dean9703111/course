# AI 使用提示詞

## 研究產品頁寫法

```prompt
請先讀取 CONTENT_LIBRARY/ANALYSIS.md，再從 CONTENT_LIBRARY/products/ 選擇三個相同系列或相近用途的產品。

請分開整理官網事實、可學習的資訊順序，以及需要重新查證的活動價格與實證數字。

產生新文案時只能使用我另外提供的事實，不要把舊產品的成分或數字套到新產品。
```

## 研究 Facebook 貼文寫法

```prompt
請先讀取 CONTENT_LIBRARY/ANALYSIS.md，再從 CONTENT_LIBRARY/social/ 找出五篇和本次任務相近的原始貼文。

請分析開場、資訊順序、句長、空行、emoji、hashtag 與 CTA，接著產生新的 Facebook 文案。可以學習結構與節奏，不要複製原句。價格、功效、人物心得與實證數字只能使用我另外提供的資料。
```
