# 產品情境圖 Prompt 模板

用途：社群貼文、廣告主視覺的「純畫面」情境照；不含文字，上方留白給後製加標題。
把 `[ ]` 內的變數換掉即可；沒特別指定就用預設值。

## 模板

```
使用我提供的產品圖，來生成一張[社群貼文]用的情境照片：

- 場景：[暖米色高級攝影棚背景，搭配香檳金絲綢布料與透明水晶展示台]
- 構圖：中央對稱構圖，展示台位於畫面下方中央，上方保留大面積留白
- 材質：[絲綢具有柔滑光澤與自然皺褶，展示台呈現透明折射與細緻反光]
- 色調：[奶油米色、象牙白、香檳金]為主，避免高飽和色彩
- 氛圍：[優雅、溫柔、成熟、精緻、奢華]，帶高級[抗老]保養品形象
- 風格：高端美妝商業攝影、精品保養品廣告、寫實棚拍質感
- 畫面層次：前景以[絲綢]包圍，中景放置展示台，背景保持乾淨柔焦
- 留白：畫面上方保留約 30–35% 空間，方便後續加入標題與文案
- 細節：高解析、材質真實、反射自然、陰影柔和、畫面乾淨
- 產品：保持包裝、瓶身比例、標籤與材質真實，不要重新設計產品外觀；不加品牌 Logo 與文字
- 比例：[1:1 正方形]，適合 [Facebook 與 Instagram 廣告主視覺]
```

## 場景變數建議

| 場景 | 材質／前景 | 色調 | 適合產品 |
| --- | --- | --- | --- |
| 暖米色攝影棚（預設） | 香檳金絲綢、水晶展示台 | 奶油米、象牙白、香檳金 | 美白修護霜、外泌體抗老精萃 |
| 浴室檯面 | 大理石檯面、毛巾、水珠 | 白、淺灰、水藍 | 煥采保濕露、潔顏產品 |
| 梳妝台一角 | 木質桌面、化妝刷、柔光窗 | 暖木、奶油白 | 眼霜、日常保養品 |
| 夏日海邊 | 白沙、海面光影、棕櫚葉影 | 天空藍、珊瑚橘、奶油白 | 煥妍防曬隔離霜、身體乳 |

## 比例對照

- 1:1：FB／IG 貼文、廣告主視覺（預設）
- 4:5：IG 貼文直式
- 9:16：IG／FB 限時動態
- 16:9：FB 封面、官網 Banner
