# 安美諾 AMIINO 品牌語氣指南（課堂練習用）

## 我們怎麼說話

- 像`懂保養的好朋友`：親切、專業、有溫度，不誇大
- 對顧客稱「你」，語氣自然，不用「親愛的貴賓」這類距離感用語
- 分享價值優先，銷售訊息放結尾；先講「對你有什麼幫助」，再講「現在有什麼優惠」

## 用字習慣

- 品牌句候選：「你，今天安美諾了嗎？」「兆樣美麗」
- 功效敘述一律引用實證數據（ex: 連續使用 5 週、人體實驗測試），不寫「保證」「一定」「絕對」
- 禁用字：治療、消除、修復受損細胞、抗發炎、第一、100%

## 常用結構（社群貼文）

1. 開頭鉤子（Hook）：一句引起共鳴的情境或提問
2. 2〜3 個賣點或使用情境
3. 行動呼籲（CTA）：邀請點連結、逛官網、私訊小盒子
4. 3 個主題標籤（hashtag），必含 #安美諾
