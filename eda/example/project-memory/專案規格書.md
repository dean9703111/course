# 會員 App 改版 — 專案規格書 v1.2

> 放進 Project「知識庫」層。這是專案的「事實來源（Source of Truth）」。

## 專案目標
提升會員回購率，將現有會員系統從「集點」升級為「分級會員 + 個人化推薦」。

## 範圍（In Scope）
1. 會員分級制度（一般／銀卡／金卡），依年消費金額自動升降級
2. 個人化首頁：依購買紀錄推薦商品
3. 推播通知中心（可開關不同類型通知）
4. 第三方登入：本期僅支援 Apple、Google

## 不在範圍（Out of Scope）
- 線上金流改版（沿用現有金流）
- 實體門市 POS 串接（列入下一期）
- 社群分享分潤機制（暫緩）

## 關鍵需求細節
### 會員分級
- 銀卡：近 12 個月消費滿 NT$10,000
- 金卡：近 12 個月消費滿 NT$30,000
- 每月 1 號重算等級，降級給予一個月緩衝期

### 個人化推薦
- 第一版採「規則式」推薦（同類別熱銷 + 回購品項），不導入 ML 模型
- 推薦結果需可解釋（顯示「因為你買過 X」）

## 已知風險
- 分級規則若頻繁調整，會造成會員客訴（需先定義清楚再凍結）
- 推薦冷啟動：新會員無購買紀錄，需有預設推薦清單
