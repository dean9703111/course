## D-001｜2026-03-08｜推薦系統第一版不導入 ML
- **決策**：採規則式推薦（同類熱銷＋回購品項），不上機器學習模型。
- **理由**：時程只有 ~2.5 個月；ML 需資料清整與驗證，風險過高；規則式已能解決 80% 需求。
- **取捨**：犧牲精準度，換取可解釋性與如期上線。
- **重新評估時機**：上線 3 個月後，視成效決定是否導入 ML。

## D-002｜2026-03-08｜第三方登入本期只做 Apple / Google
- **決策**：LINE 登入延後至下一期。
- **理由**：LINE 登入需額外審核與測試；本期人力吃緊。
- **影響**：部分習慣 LINE 登入的會員體驗未改善，需在 FAQ 說明。

## D-003｜2026-04-19｜新會員冷啟動用「本月精選」
- **決策**：無購買紀錄者，首頁顯示行銷維護的「本月精選」清單。
- **理由**：避免新會員看到空白或亂推薦；行銷可控。
- **負責**：行銷每月 25 日前提供下月清單。
