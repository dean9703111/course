# 實戰演練 9：讓 Cowork 整理一個資料夾（操作說明）

> 沒有「夠亂」的資料夾可以練習？用這包就好。
> 這裡刻意塞了**混合格式 + 爛檔名**，模擬一個真實的「下載／桌面」資料夾。

## 包裡有什麼（故意很亂）

| 檔案 | 為什麼放它 |
|---|---|
| `週會記錄_第14次.pdf` | 文件型，會議記錄 |
| `報價單_明亮照明_0603.pdf` | 文件型，廠商報價 |
| `產品規格_v2.xlsx` | 表格型，產品規格 |
| `截圖 2026-06-10 下午2.31.45.png` | 截圖，**檔名沒有意義** |
| `IMG_4821.png` | 照片，**檔名沒有意義** |
| `未命名文件.md` | 一張沒歸類的便條 |

這一包同時可以練到課程裡的三件事：
1. **多格式彙整**——一個資料夾混著 PDF／Excel／圖片，請它讀完彙整成一份總表。
2. **圖片批次重新命名**——把 `截圖…`、`IMG_4821` 依內容改成看得懂的名字。
3. **分類歸檔**——請它先「只掃描、只建議」，你核准後再動。

## 怎麼做（守住「AI 建議、人工核准」）

1. 解壓整包，放成一個資料夾，指給 Cowork。
2. 先請它**只掃描、只分類、不刪除、不搬移**，產出一份「整理建議清單」。
3. 檢視清單，確認分類邏輯沒問題。
4. 再核准它執行——**改名、歸檔可以做；刪除一律由你拍板**。

```text
這個資料夾很亂，請你先「只掃描、只分類、不要刪除也不要搬移」：
① 列出每個檔案是什麼、建議歸到哪一類
② 針對檔名沒有意義的圖片（截圖、IMG 開頭），依內容建議一個看得懂的新檔名（日期＋主題）
③ 最後把整個資料夾的重點，彙整成一份總表

清單我確認後，再讓你實際改名與歸檔；刪除類動作一律先問我。
```

## 自我檢查表

- [ ] 它是**先給清單**，而不是直接動手刪改
- [ ] 改名建議是**看得懂的**（例如 `2026-06-10_推播設定頁_截圖.png`）
- [ ] 彙整總表有抓到每份文件的重點
- [ ] 全程沒有未經你同意就刪除任何檔案
