1
元數據 METADATA
告訴 Claude「你是誰、什麼時候該出場」。寫在 SKILL.md 開頭的 YAML frontmatter。
▶ 點擊查看範例
--- SKILL.md --- --- name: git-smart-commit description: 當使用者要 commit 程式碼時自動觸發，依據變更內容 產生符合慣例的 commit message ---
2
提示詞 PROMPT
Skill 的「大腦」與「SOP」。寫在 SKILL.md 主文中，告訴 Claude 步驟、原則、產出格式。
▶ 點擊查看範例
--- SKILL.md（接續上面）--- # Git Smart Commit ## 執行步驟 1. 執行 `git diff --staged` 2. 依變更類型分類（feat/fix/...） 3. 用一行 50 字內的繁中描述 4. 詢問使用者是否 commit ## 原則 - 不主動 push - 不修改 .env 等敏感檔
3
程式腳本 SCRIPTS
把重複、確定性的工作交給程式（Python / Node.js），SKILL.md 只負責「呼叫」，省下大量 token。
▶ 點擊查看範例
--- scripts/build.py --- import sys, json from pathlib import Path def build(md_path): # 將 markdown 轉成 HTML md = Path(md_path).read_text() html = render(md) out = md_path.replace('.md', '.html') Path(out).write_text(html) print(f"✓ {out}")
4
參考資源 REFERENCE
補充判斷依據（範例、規則、樣板）。AI 需要時才會載入，避免 SKILL.md 過長。
▶ 點擊查看範例
--- reference/components.md --- # 元件對照表 | Markdown | HTML | |---|---| | `# 標題` | `<h1>` | | `![圖]()` | `<figure>` | | `[flow]` | `.flow` | # AI 遇到「轉 Markdown」 # 任務時才會載入此檔
