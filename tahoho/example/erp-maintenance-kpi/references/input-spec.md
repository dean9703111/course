# 輸入檔欄位規格

三張工作表名稱必須完全一致：`DATA`、`完工資料`、`未完工資料`。欄位順序不限、欄名須一致（半形括號）。多餘工作表會被忽略。

腳本 `--check` 只驗「必填」欄位是否存在；「選填」缺少時該欄視為空白，「可省略」欄位程式一律重算。

## 常見格式問題

- 欄名有前後空白：腳本會自動 strip，可放心。
- 「停機時間（分）」用了全形括號：會被判為缺欄，請改成半形 `停機時間(分)`。
- 三張表分在三個檔案：合併成一份 xlsx（每張表一個工作表）再跑。
- 完工資料的完成日空白：該列會被排除並記在校正紀錄；全部空白則無法推算期間，需 `--period`。
- 維修類別大小寫不一（bd／Bd）：腳本會轉成大寫；但 BD 以外的代碼（如 PM）會被當成獨立類別，不會進 BD 類 KPI 表。
